# CEMS v9.2.4 학습 콘텐츠 추가 가이드

이 기능은 외부 API를 앱에 연결하지 않고, 일반 대화형 생성 모델에서 만든 작은 코스 JSON을 **내 기기에서 검사한 뒤** 가져오는 방식입니다.

## 권장 흐름

1. 앱에서 **학습 → 학습 콘텐츠 추가**를 엽니다.
2. 언어, 수준, 코스 제목, 집중할 생활 기능, 단원 수를 입력합니다.
3. **언어별 프롬프트 만들기**를 누르고 생성된 프롬프트를 복사합니다.
4. 사용 중인 생성 모델에 프롬프트를 한 번만 붙여넣습니다.
5. 모델이 반환한 JSON만 복사해 앱의 검사 칸에 넣습니다.
6. 자동검사 결과의 오류가 0건일 때 문제 미리보기를 확인하고 가져옵니다.
7. 가져온 코스를 활성 코스로 선택해 학습합니다.

## 한 번에 적게 만드는 이유

- 한 번에 **1~4단원**만 만드십시오.
- 단원 하나는 생활 기능 하나, 본 학습 6문항, 보충 3문항, 기준선 1문항, 3일 전이 1문항, 14일 유지 1문항으로 제한합니다.
- 대량 생성은 자연스럽지 않은 문장, 정답 누락, 중국어 문자·병음 불일치, 평가 문장 재사용을 늘립니다.

## 자동검사가 확인하는 것

앱은 구조, 필수 문제 유형, ID·참조, 실제 채점기 정답 판정, 뚜렷한 오답 거부, 영어·중국어 프로파일, 평가 문장 누출, 기존 설치 코스와의 충돌, 버전 증가 여부를 검사합니다.

자동검사 통과는 원어민 검수를 뜻하지 않습니다. 가져온 콘텐츠는 `machine_validated_unreviewed`로 저장되며, 자유 회화·장문 작문·미묘한 화용 자연스러움까지 보증하지 않습니다.

## 업데이트 규칙

- 같은 코스를 수정할 때 `pack.version`과 변경된 `unit.version`을 반드시 올립니다.
- 같은 버전에서 내용만 바꾼 JSON은 차단됩니다.
- 설치된 단원 ID, task ID, benchmark ID, measurementKey는 가능하면 보존합니다.
- 내장 시작 코스 ID는 자체 코스에서 재사용하지 않습니다.
- 새 코스에는 고유한 `packId`, `courseId`, `unitId`를 사용합니다.

## 학습 중 문제 발견

최종 피드백에서 다음 중 하나를 신고할 수 있습니다.

- 정답 판정 이상
- 문장이 부자연스러움
- 지시가 모호함

신고 파일은 위치 정보와 선택 메모만 저장하며 현재 입력 답안을 자동 수집하지 않습니다. 신고가 쌓인 뒤 앱의 **수리 프롬프트**를 사용해 문제가 있는 최소 필드만 수정하고, 버전을 올린 다음 다시 검사하십시오. 학습자의 신고 답안을 자동으로 정답에 추가해서는 안 됩니다.

## 코스 운영

한 번에 한 코스만 새 단원 대상으로 활성화됩니다. 활성 코스를 바꿔도 이전 코스에서 이미 예약된 오류 보충, 3일 전이, 14일 유지 문제는 오늘 계획에 남습니다.

## 개인정보와 백업

콘텐츠 생성과 자동검사는 로컬에서 진행됩니다. 생성 모델에 개인 학습 기록이나 백업 파일을 붙여넣지 마십시오. 코스와 학습 기록은 정기적으로 CEMS 백업으로 보관하십시오.
