# v9.4.4 외부 JSON 라이브러리 안내

## 지원 형식

- `cems-seed-3`
- `cems-routine-1`
- 단어·표현·문법·예문 배열을 포함한 일반 JSON

앱은 배열 경로와 행 필드를 자동으로 탐지합니다. 원본 행은 `raw`에 그대로 보존되고, 학습에 필요한 대표 필드는 별도로 정규화됩니다.

## 저장 원칙

- 기존 단어 DB와 외부 자료 DB는 분리합니다.
- 기존 정답률, FSRS 상태, 복습 예정일과 학습 기록을 덮어쓰지 않습니다.
- 동일 항목은 학습 시점에만 통합합니다.
- 교과서 정합형 > 자동 보강형 > 일반 외부 자료 순으로 대표 값을 선택합니다.
- 예문·태그·관계어·출처 참조는 가능한 한 합집합으로 보존합니다.
- 출처별 원본 행은 카드 상세 화면에서 각각 확인할 수 있습니다.

## 권장 절차

대용량 파일은 한 번에 하나씩 등록하십시오. 등록 중에는 앱 탭을 닫지 마십시오. 동일 파일을 다시 등록하면 기존 동일 출처를 9.4.4 형식으로 교체합니다.
